# 油缸.jpg — 尺寸描述

## 图像识别
重型 **耳环式双作用液压油缸**，缸筒深蓝，活塞杆镀铬伸出，缸上带集成阀块与硬管。

## 必要尺寸（联网查询）
| 项目 | 常见范围 | 说明 |
| --- | --- | --- |
| 缸径（内径） | **50–200 mm**（中型常见 80–125） | 决定推力 |
| 活塞杆直径 | 约 0.5–0.7×缸径 | |
| 行程 | **200–1500 mm** 不等 | |
| 安装中心距（缩回） | 行程 + 结构长度 | 耳环中心到中心 |
| 耳环销孔 | 常见 φ30–φ80 | |

## 备注
废钢场景可估：缸筒外径约 100–200 mm，总长（含杆）常超过 1 m。
