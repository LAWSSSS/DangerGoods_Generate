# 密封胶罐.jpg — 尺寸描述

## 图像识别
两只 **白色圆柱塑料广口瓶**（无标签），盖型分别为平盖与防伪拉环翻盖，外形接近口香糖/药片广口瓶。

## 必要尺寸（联网查询，同类包装）
| 项目 | 常见范围 |
| --- | --- |
| 外径 | 约 **50–60 mm** |
| 总高（含盖） | 约 **80–110 mm** |
| 容量 | 约 40–100 片口香糖瓶 / 同类药瓶体积 |

## 备注
图中无品牌铭文。若业务上“密封胶罐”指建筑密封胶，则更常见为 **300 ml 铝塑软管**（长约 220–230 mm、管径约 45–50 mm），与本图外观不符。
