## 主要问题

1. **生图没有看到原物照片。** 此版本首轮仅输入原背景，第二、三轮输入原背景和上一轮生成图；原物文件只参与类别选择，没有进入Wan或原尺寸评估。本轮照片仅送到独立对照。原物主色、开口状态、具体零件及连接不能由类别名可靠约束。
2. **融合描述与原貌要求冲突。** 原代码要求异物材质、锈迹和颜色与废钢一致，并禁止亮面；这会将白色塑料、喷漆或镀铬物体推向锈铁外观。密封胶罐的白色封盖罐变成长条锈罐，是明显实例。
3. **原评估侧重尺寸。** 它不看原物照片；尺寸合格或不要求重试即可退出。新增独立检查发现，即使第三轮尺寸判合格，主体、颜色、连接、支撑或落点仍可能不符。本轮抑制了提前退出，保留原始评价及其原本停止条件，使全部三轮可比较。
4. **反馈链路回输前轮图。** 后两轮会拿上一轮结果作为图像参考，错误形体和过度纹理也同时进入输入；完整对照中出现噪点累积。该测试没有关闭前图的控制组，因此不能把所有退化单独归因于这一因素。
5. **位置按四角概率采样。** 代码没有先验证目标凹槽及承托/限位，姿态也不由真实槽向决定。独立对照发现凸起摆放、位置偏移或支撑不明。它仍是单张照片上的模型判读，未作实际重力测量。

进一步修复宜先固定原物参考和原背景输入、保留主色/材质/关键结构，并把身份错误与尺寸反馈分开；再单独核对有真实承托的落点。增加迭代次数不能补足缺失的身份与支撑条件。本轮没有更改被测试的生成算法，也没有追加其他对照批次。
