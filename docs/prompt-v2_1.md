# 场景适配 Prompt 2.1

日期：2026-10-15。程序版本：0.3.1。任务契约保持2.0，增加可选的结构化提示字段。

## 修改依据

查看上一次两件生锈物品的实际提示词、原背景、输出预览和辅助审阅记录后，本轮集中修改提示词。
气瓶的残漆较鲜亮，阀体有偏金的反光，阀门承载关系不清楚；这是对现有图片的视觉观察，不是人工质量验收。

原提示词将身份、落位和外观写在连续段落中，身份特征重复；参考图的颜色要求容易与背景适配混在一起。
原文还包含“按已确认支点”和“宿主约束Mask”等陈述，而实际A模式预览缺少已确认的支点/物体蒙版。

## 新格式

统一使用九个区块：

1. 任务与优先级。
2. 输入图职责及逐图编号。
3. 背景光色与相机风格。
4. 物体身份与结构。
5. 完整投影与落位。
6. 按部件旧化与颜色呈现。
7. 接触、遮挡与边缘融合。
8. 禁止出现的结果。
9. 输出与画面检查。

背景是曝光、白平衡、局部对比、高光、黑位、清晰度和噪声的依据；物品参考提供身份、连接、材料分区与可见旧化线索。
保留不同材质的本色差异，不要求物体与背景RGB均值相等，也不使用固定“压暗30%”等未标定数值。
色调提示和原图冲突时，以当前原图放置点附近的实际成像为准，避免把本场景的灰褐风格套用到所有背景。

## 编辑位置与使用

- 通用规则：`src/fusion_engine/templates/scene_fusion_v2_1.yaml`。
- 场景外观：任务JSON的`prompt_directives.scene_style`与`negative`。
- 逐件补充：`objects[].prompt_directives.identity / appearance / contact / occlusion`。
- 两件修订配置：`config/controlled/rusted_S01.prompt-v2_1.json`、`rusted_S20.prompt-v2_1.json`。
- 可阅读的导出：`config/controlled/formatted_prompts/v2_1/S01/prompt.txt`与`S20/prompt.txt`。

每份导出同时包含`prompt.json`：九个区块、参考编号、模板版本、模板SHA-256和最终文本。
TXT是导出的阅读副本。要影响后续实际请求，编辑YAML或任务JSON中的结构化字段，再重新导出；单独改TXT不会自动改程序请求。

```bash
# 只格式化提示词，不要求Mask/支撑输入已经齐全，也不请求模型
python -B fusion.py prompt config/controlled/rusted_S01.prompt-v2_1.json \
  --output work/prompt-v2_1/my-S01

# 离线构造实际请求摘要，查看实际提交文本
python -B fusion.py request-preview config/controlled/rusted_S01.prompt-v2_1.json \
  --provider-config config_bailian.yaml --output work/prompt-v2_1/my-S01-request.json
```

生成适配器直接提交同一文本，移除旧的Python字典式参考前缀。参考关联表留在审计JSON中。
运行记录保存`joint_prompt.txt/json`；请求摘要记录`prompt_format_version`和`prompt_template_sha256`。
通用模板进入源码指纹，后续修改模板会改变指纹。
