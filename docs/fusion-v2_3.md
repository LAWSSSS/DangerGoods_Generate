# 完整画幅、承托与局部光色修订

程序 **0.5.0**，提示词 **2.3**，任务契约仍为 **2.0**。日期：2026-10-15。

## 1. 本次修订的来源

用户反馈：部分物品悬浮，颜色/风格与背景不符；输出必须保留原图尺寸，不裁切。允许重新生图与纠正，要求先修算法再修提示词。

此前 `output/side-tests/v2_2-two-items-20261015T165255` 的气瓶/阀门实际测试中，局部背景差分 P90 分别为72和57，超过40的可靠差分阈值。候选诊断返回 `UNKNOWN` 后，旧流程跳过了光色校正和前景恢复，处理后诊断图与处理前图一致。这不是“执行校色后仍不一致”的证据；实际问题是处理没有执行。之前的局部上下文裁切路线也不符合本次明确的完整画幅要求。

本次保留这些失败记录，不把旧诊断图当成融合成功结果，不通过提高40阈值掩盖局部背景重绘。

## 2. 已实现的处理顺序

1. 校验背景/参考哈希、原始宽高、显式区域和每次任务预算。
2. 以完整原图为生成输入，转换到接口支持的像素上限时只做同画幅等比缩放，不裁切视野。
3. 初次生成以完整投影和接触区的并集加12px余量生成 Wan `bbox_list`；纠正生成允许使用显式编辑包络。早期将宽编辑包络直接作为初次bbox，模型易将物体扩到整个范围，已经修正。该参数是编辑范围建议，不是对象形状或原生二值Mask。
4. 保存接口返回的原始字节；按照既有显式Alpha政策和同长宽比归一化恢复工作画布。
5. 在编辑区外提取SIFT背景特征，以Lowe比例筛选、RANSAC相似变换拟合小幅背景漂移；保存匹配数、内点、误差、变换矩阵与覆盖范围。拟合不可靠返回 `UNKNOWN`，不声称成功。
6. 使用配置中的视觉模型观察本次候选，提出可见外缘、内部孔洞、实体种子点、分表面区域、支撑及结构问题。统一约定0–1000坐标，然后将所有坐标字段统一除以1000；响应未复述单位时明确记录按请求约定解释的假设，不猜测或静默裁断越界值。缺失的审阅结论记为UNKNOWN，几何必要字段与数值仍校验。可选剔除额外JSON字段并记录字段名，单一报告实例对应单一任务实例时可以记录明确的ID关联假设；多实例ID不匹配时拒绝猜测。建议绑定候选哈希，不能作为训练分割真值或人工验收。
7. 以候选的语义点作GrabCut前景种子、候选多边形作概率范围、扩张语义外框范围外及内孔核心作背景种子。粗轮廓外另留8%搜索余量，避免紧贴VLM多边形硬裁真实体积。不把计划OBB或计划Mask直接当候选实体。旧的差分方法仍保留作独立可选路线。
8. 检查估计实体与允许区域、禁入区、计划轮廓、支点和独立场景承载面的二维关系。分割不足、支点远离主体、主体离开编辑区等情况不能自动通过。
9. 有可靠且完整位于编辑范围内的候选轮廓时，即使接触/位姿有风险，也可执行局部光色处理供诊断；几何风险仍保持拒收。候选实体越出编辑范围直接跳过渲染，不用编辑Mask截成锥形、扁条或缺损物体。
10. 对同位置、未编辑的背景ROI进行原图/候选配对。剔除过暗过亮像素，以线性RGB的log2比值估计曝光和零均值通道偏移，进行MAD稳健筛选；不可靠采样区逐一记录并排除。可靠采样区不足则明确处理失败。
11. 只在估计实体内应用有界光色校正；对本次候选的残漆、字迹、手轮、阀体等表面区域分别限制彩度和过强亮部。VLM未能定位的部位跳过，不盲目套用预设图像位置。
12. 只在测得二维近接触的承载表面允许补有限的接触遮蔽；已有生成暗部会减少新增量。不得用一团黑影桥接实体间隙。此步骤不是三维光照模拟。
13. 只将估计实体作为候选图像的复制范围，接触区域不再整块复制背景，防止方块状暗部。有限接触遮蔽单独计算，最后恢复保护像素。输出PNG重新读取后检查原图宽高和保护区差异。
14. 几何/支撑/处理失败本身即可产生修复反馈；不再仅依赖VLM说“refine”才重生。每次保留完整原背景和原参考，启用 `refinement_source=previous_candidate` 时另外提供上一候选作为最后一张纠正目标，写明输入职责和候选哈希；预算耗尽停止并保留真实结果。

### 低细节落位引导

`generator.layout_hint=procedural_proxy` 时，程序在完整原图上依据未确认的设计投影画低细节色块、圆柱横向明暗提示和部件开口。所有原场景边界保持不变。引导图作为额外完整画幅参考，真实原图仍单独提供；模型必须重新生成参考中的真实旧物并替换简单色块。

这一步没有粘贴六视图照片像素，没有调用三维渲染器，不声称恢复了法线、深度或物理载荷，也不属于接口原生ControlNet/深度控制。引导图只表达位置、尺度和粗结构，绝不能被交付为最终融合图。请求摘要保存其方法、输入尺寸、编码哈希及 `reference_pixels_pasted=false`。

### 仅用于观察的局部放大

`candidate_geometry.analysis_context=true` 时，VLM观察原背景和候选在同一位置的局部放大，以减少小目标种子点与边缘误差。分析输入保存在 `analysis/*.observation-original.png` 和 `*.observation-candidate.png`，其坐标按记录的矩形逆映射回完整原图。生成请求仍发送完整画幅；最终PNG也保持完整原尺寸。不得将这些分析局部图当作生成结果。

## 3. 承托区域的来源与限制

旧2.2示例中的小支撑框主要围绕预定代理底边构造，不能独立证明原图那里存在可承载实体。2.3示例先识别原场景中的较宽钢面/可见地面，再选择落位，保留其较完整的区域，不从物体底边扩张出“地面”。

本次曾调用已配置VLM提出支撑方案，但气瓶的文字角度与数值矛盾，中心也偏离其支撑区域。因此没有照单采纳；示例落位经过原图视觉核对后另作建议。相关请求与返回记录位于 `work/fusion-v2_3/support-request.json`、`support-proposals.json`。

这些区域仍为 `source=proposal, confirmed=false`，载荷仍为 `unknown`。没有深度标定、CAD、载荷测量和真实物理求解。估计轮廓到指定承载面近接触只是一项二维排错依据；视觉上看似接触也不证明3D稳定性。

## 4. 完整画幅契约

```json
{
  "generator": {
    "adapter": "bailian",
    "route": "guided_generation_then_restore",
    "output_registration": "resize_same_aspect",
    "preserve_full_frame": true,
    "context_crop": false,
    "layout_hint": "procedural_proxy",
    "refinement_source": "previous_candidate",
    "bbox_padding_px": 12,
    "alpha_policy": "near_opaque_unassociated_rgb",
    "near_opaque_min_alpha": 251
  }
}
```

`preserve_full_frame=true` 与 `context_crop=true` 同时出现时，在模型请求前报错。新示例的请求区域必须是 `[0,0,3840,2160]`，最终PNG必须是 `3840×2160`。原2.2的历史裁切配置/导出保留作追溯，不自动修改为新版本。

阿里云官方说明中，Wan2.7参考图编辑的输出总像素上限为 `2048²`，`2K`跟随最后一张输入的长宽比；更高4K能力有不同适用路线。因此本程序保持用户的Wan模型配置，用同画幅显式归一化恢复原图大小，不宣称模型原生生成3840×2160，也不通过裁切凑尺寸。接口输入缩放、返回尺寸、归一化与最终尺寸均单独记录。[官方图像编辑说明](https://help.aliyun.com/zh/model-studio/wan-image-edit)、[官方API参数说明](https://help.aliyun.com/zh/model-studio/wan-image-generation-and-editing-api-reference)。

## 5. 关键参数

| 模块 | 本次配置 | 作用与边界 |
|---|---|---|
| 背景配准 | 最大边1800，至少35内点；旋转≤2°；绝对log尺度≤0.04；归一化平移≤0.025；中位重投影误差≤4px | 只纠正小幅2D漂移，不能纠正局部重绘、主体姿态或真实碰撞 |
| 轮廓估计 | `vlm_seeded_grabcut`，种子42，3轮，工作最大边1000 | VLM粗语义+GrabCut，不是人工真值；内部模型采样不开放 |
| 接触检查 | 实际估计边界到独立承载面的局部间距；验收阈值4px | 缺少实体/局部边缘时UNKNOWN；阴影本身不算接触 |
| 配对光色 | 最少128中间调像素，内点比例≥0.6，线性残差≤0.06 | 每个坏ROI单独排除，不放宽原阈值 |
| 曝光/通道 | 曝光有界±0.4stop，零均值通道偏移绝对值≤0.18stop，强度0.75 | 校正生成偏移，不估计真实开尔文色温或物理反射率 |
| 表面/成像 | 按下表的场景工作参数；高斯sigma0.45px；融合内缘2px | 只作用于对应的估计实体/表面，不全图模糊调色 |
| 接触遮蔽 | sigma3px，新增暗度上限0.12，局部搜索40px | 只在二维近接触处、原承载面和接触范围内；不补大范围投影 |
| 每件预算 | 图像调用≤2，VLM调用≤4，候选≤2 | 失败请求同样记账；YAML旧total_num不会启动批量100张 |

分表面工作参数使用浮点CIELAB的L*和C*，不是LAB8字节值。以下均为场景调节建议，不是实测反射率；强度和内缘渐变使其成为有界趋向，不保证所有输出像素都低于目标值。

| 气瓶残漆 | 0.62 / 22 | 58 / 0.60 | 0.85 |
| 气瓶旧字迹 | 保留原彩度 | 48 / 0.28 | 0.85 |

## 6. 提示词2.3

算法基础检查完成后才修改模板。仍按九个区块格式化，统一由计划、CLI导出和真实API共用：

1. 完整场景和承托优先级。
2. 六视图身份职责及棚拍光色禁止迁移内容。
3. 放置邻域的受光/阴面、灰尘、残漆、白字与成像。
4. 刚体结构、开放轭架、机械连接、孔洞负空间。
5. 原图坐标、正负角定义、完整投影与贴合承载面。
6. 分表面风化与旧漆响应。
7. 可见承载、遮挡、接触窄缝与边缘。
8. 具体悬浮/穿模/棚拍色彩缺陷。
9. 完整画幅、四边内容与输出复核。

不强迫一根钢条从所有物体中间穿过；不为完成任意遮挡比例新增废钢。提示词描述是目标，不声称模型真的做过三维重建、深度推理、逐像素蒙版或物理光追。

## 7. 复现命令

私有API配置不入Git，模型名称和凭据仍从用户的 `config_bailian.yaml` 读取。

```bash
python -B fusion.py plan config/controlled/v2_3/S01.json --output work/my-v23-S01-plan
python -B fusion.py request-preview config/controlled/v2_3/S01.json --provider-config config_bailian.yaml --output work/my-v23-request.json
# 下列为真实模型请求，每件有独立预算和运行目录。
python -B fusion.py run config/controlled/v2_3/S01.json --generate --provider-config config_bailian.yaml
python -B fusion.py run config/controlled/v2_3/S20.json --generate --provider-config config_bailian.yaml
```

`scripts/create_v2_3_cases.py` 可在目标目录不存在时重建两件示例，不进行模型调用。示例的区域和3840×2160变换只适用于这张背景；新场景必须独立选承载面和ROI，不能照搬其坐标。

## 8. 实际验证与结果记录

本次先执行了合成夹具检查，覆盖语义点辅助分割、真实承载边界间隙、悬浮失败、背景配准、坏ROI剔除、物体外像素不变、全画幅与裁切冲突。检查通过；记录在 `work/fusion-v2_3/algorithm-checks.json`。这些是算法基础行为检查，不代表真实生成画质已经达标。

前两轮真实复测共8次图像请求、16次VLM请求，均按每件2次图像/4次VLM预算执行。早期暴露的坐标单位混用、额外JSON字段、单实例ID别名、紧轮廓裁断、编辑包络截主体和接触框暗块均据实际记录修正；失败候选完整保留。独立支撑建议另调用VLM一次；观察协议诊断另调用4次，前3次失败、最后一次取得有效结构化响应。部分早期诊断请求文件曾覆盖，仅最后一次完整请求/响应保留，未补造丢失的响应或请求ID。

落位引导的最后小样及最终静态检查结果另附实际记录。A模式只能作为可审阅效果预览，不能自动提升为B/C已验收图或导出训练标注。

### 本轮实际结果

本次总计10次图像请求、33次VLM请求（流程28、独立支撑建议1、协议诊断4）。后两轮复用已有候选，没有增加图像请求。两张最后处理图均完整3840×2160，背景保护区变化像素为0，二维局部接触检查均PASS。

气瓶在相同估计物体区域的彩度C*第90百分位由43.92降至25.65，阀门亮度L*第90百分位由77.87降至69.49，证明局部处理真实发生；这些统计不能单独证明自然度。局部观察后气瓶估计轮廓由242939像素收敛至120238像素，计划可见IoU由0.410升至0.780，修复了误包含大量背景钢板的问题，未放宽IoU或接触阈值。

气瓶仍为 `CONCEPT_ONLY`；阀门因辅助身份审阅提示结构细节问题为 `REJECTED`。最终辅助审阅对两者仍建议修正风格/接触细节，不将意见冒充物理测量或宣称图像已验收。没有导出训练标注。
