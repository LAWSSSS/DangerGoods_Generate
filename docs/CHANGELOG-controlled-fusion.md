# 受控融合引擎版本说明

## 0.3.0 — 2026-10-15

### 工程实现

以用户提供的超级详细实施手册V2.0作为需求依据，新增独立受控执行入口。
引入任务/验收契约2.0、多物品OBB与局部遮挡、六Mask、按部件旧化、局部成像、硬门禁、预算、实际标注与哈希绑定人工审核。
Wan/Seedream和Qwen/Doubao接入复用先前本地框架的密钥隔离与传输基础；没有把先前框架的检查结果冒充本版检查结果。
新增手册工具、目录迁移、S01/S20三份草案、章节实现映射。

### 参数与行为

- 图像/VLM模型仍按外部config_bailian.yaml绑定。
- 尺度使用完整投影，不再把旧可见比例/透明度作为完整尺寸/融合真实性的保证。
- 模式B/C缺少证据时INPUT_REQUIRED；生成结果仍需独立实际轮廓和人工检查。
- 任务预算替代旧批次数作为新入口的执行上限，旧YAML本身未改写。
- 当前原生二值inpaint、三维/透明/软体求解未接入，不宣称已执行。
- 历史LAB参数作为独立case工具保留，不默认全局应用。

### 资料版本

原始手册保留为docs/specifications中的V2.0副本，未改写历史事实。
本版使用说明与实现矩阵分别记录已经写成的程序、需要外部证据的输入，以及尚未接入的专用能力。
本次实现未启动新的付费生成批次；草案、规划图和代码检查不是自然融合效果已达标的证明。
已执行检查与离线诊断的具体范围见controlled-fusion-checks-20261015.md。
